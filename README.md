# Tim SEMPAKTELES — Ketahanan Pangan
Proyek Web Development untuk Soedirman Technoporia 2026

## Struktur Repositori Tim
Setiap anggota tim menaruh source code proyek aplikasinya di dalam folder masing-masing:

- `Tita/` : **AgriScan Pro** — Sistem Pendukung Keputusan Pertanian untuk Lahan Luas dan Pekarangan (Next.js, TypeScript, Tailwind CSS, MobileNetV2, API BMKG).

### Cara Menjalankan Bagian Tita (AgriScan Pro)
```bash
cd Tita
npm install
npm run dev
```
Akses di browser: `http://localhost:3000`
